FAQ

Answers for the group chat

Everything your leaguemates will ask when you tell them the draft order gets earned this year.

Does everyone need an account?

No. Only the commissioner creates an account. Members tap the shared link on their phone, type a name, and go — no app install, no signup, no email.

What if someone never takes it?

The commissioner closes the competition whenever they decide time's up. Anyone who never competed is marked DNF and picks last. Nobody can stall the league.

What about people who are bad at tests?

There are two events — the Wonderlic-Style Test for wits and The 2D Yard Dash for reflexes — plus the Skill & Wit Combine, which runs both and averages your finishing position in each. One skill never decides everything.

What if someone cheats?

You know these people. The clock allows about twelve seconds per question, the server enforces exactly one attempt with server-side timing, and they'd have to be smart enough to cheat — which is sort of the point.

How does the competition actually run?

Everyone competes on their own time from their phone — no scheduling, no Zoom call. The clock starts when they start. When the last member finishes, the draft order reveals with an animation, last pick up to the 1.01, and everyone gets the same results link.

What's the best way to decide fantasy draft order?

Not a random number generator. Same task, same clock, one try each — highest score picks first, ties broken by completion time. That's an order nobody can argue with.

Just want a random draft order?

We built a free draft order randomizer with an animated last-to-first reveal. Use it once, then make them earn it next year.
